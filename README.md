# Приложение «Конфигуратор авто»

На основе пройденного материала необходимо написать приложение «Конфигуратор авто». Приложение должно выводить на экран изображение автомобиля с помощью компонента `Image`. Пользователь должен иметь возможность выбирать цвет автомобиля с помощью `RadioButton`’ов или `selectable` компонентов.

Также пользователю должен быть предоставлен выбор комплектации автомобиля с помощью `RadioButton`’ов. В зависимости от выбранной комплектации должна меняться предполагаемая стоимость автомобиля, которая отображается в компоненте `Text`.

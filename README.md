# Приложение «Студент университета»

Необходимо создать проект с названием `FirstAppJetpackCompose`. В рамках этого проекта нужно написать `Composable` – функцию для вывода информации «Студент университета Urban: `имя студента`». Функция должна принимать параметр имени строкового типа. Размер шрифта должен составлять `16.sp`, а цвет текста – красный.

Для успешного выполнения задания необходимо выполнить следующие шаги:

1. Создать проект с названием `FirstAppJetpackCompose`.
2. Написать `Composable` – функцию для вывода информации «Студент университета Urban: `имя студента`».
3. Установить размер шрифта на `16.sp` и цвет текста на красный.
4. Запустить первое приложение на эмуляторе и устройстве.
